# __Willkommen im Dragonsoft-Leitfaden für Schüler__

Diese Website soll als Anleitung für das Lernspiel Das Gyms und das MINT Orakel dienen.
## __Steuerung__

Das Gyms kann über die Tasten **WASD** gesteuert werden.

## __Die Karte__

Die bisher dargestellte Karte soll das Gymsl darstellen, genauer gesagt einige Räume und Flure des A-Blocks.
Andere Räume können erreicht werden, indem man zu den Türen geht. 

## __Die Lehrer__

Die Lehrer sind durch Avatare innerhalb des Spieles dargestellt.    
Um den Lehrern eine Frage zu stellen, auf die Lehrer zugehen und **e** drücken. 

Den Lehrern können nur Fragen über ihre jeweiligen Fächer gestellt werden.
Die Fragen und Antworten der KI werden gespeichert.
